# Agentbriefs: håndverk i Agder og Telemark

Kjør de tre første rollene parallelt. Synteseagenten starter først når de tre leveransene finnes. Alle skal svare på norsk, bruke lenker på faktapåstander og flagge usikkerhet. Ingen skal kontakte personer, publisere eller endre nettsiden.

## Felles ramme

Lars Erik Brekne Johnsen skal undersøke et tilbud til små byggrelaterte håndverksbedrifter i Agder og Telemark, vanligvis 5–30 ansatte. Tilbudet er ikke et nytt fagsystem og ikke et generelt KI-kurs. Det er en startpakke: kartlegg én tidstyv, bygg én enkel KI-støttet arbeidsflyt og overlever en trygg rutine.

Posisjonering som skal testes, ikke tas som gitt:

> Håndverket bestemmer. KI gjør forarbeidet.

Målgruppen skal møtes med driftsnært språk: tilbud, kundesvar, befaring, dokumentasjon, avvik, planlegging, lærlinger og mindre kveldskontor. Unngå teknologihype og løfter om garantert inntekt.

## 1. Konkurransespeider

```text
Kartlegg konkurransen om praktisk arbeidsflythjelp til små håndverksbedrifter i Norge, med særlig relevans for Agder og Telemark.

Finn minst åtte aktører fra tre ringer:
1. Direkte KI-rådgivere og kursleverandører.
2. Fagsystemer, programvare og leverandører for bygg/håndverk.
3. Alternative rådgivere, nettverk og kurs som konkurrerer om samme tid og budsjett.

For hver aktør: navn, faktisk tilbud, målgruppe, konkret løfte, CTA/pris hvis synlig, bevis/case, synlige kanaler og URL. Skill fakta fra analyse. Avslutt med maksimalt fem posisjoneringsmuligheter for Lars, og marker hvilke som må testes i samtaler.

Ikke kontakt, publiser eller skriv til nettsiden.
```

## 2. Kanalspeider

```text
Undersøk hva eiere og ledere i små byggrelaterte håndverksbedrifter i Agder og Telemark leser, deltar på og har tillit til.

Prioriter fagmedier, byggmesterforeninger/laug, opplæringskontor, byggevarehandelens proffmiljøer, leverandørnettverk, arrangementer, podkaster og relevante digitale flater.

Lever en prioritert kanaliste med målgruppe, regional relevans, dokumentert aktivitet, mulig faglig inngang for Lars og URL. Finn også kildebelagte tegn på hvilke driftsproblemer målgruppen er opptatt av. Avslutt med fem budskapsvinklinger på målgruppens språk, tydelig merket som testhypoteser.

Ikke kontakt, publiser eller foreslå betalt annonsering før budskapet er validert i samtaler.
```

## 3. Prospektspeider

```text
Bygg et kildebelagt utvalg av små byggrelaterte håndverksbedrifter i Agder og Telemark. Mål: 30–50 virksomheter med omtrent 5–30 ansatte når det er synlig.

Bruk Brønnøysundregistrenes åpne Enhetsregister som primærkilde. Dedupliser på organisasjonsnummer. Bruk bedriftenes nettsteder og Proff eller lignende bare til manuell kontroll.

For hver kandidat: orgnr, navn, kommune, segment, antall ansatte når synlig, Brreg-URL, nettsted, tjenestetyper med kilde, mulig arbeidsflyt-hypotese, kvalitet_status og usikkerhet.

Ikke finn eller lagre private kontaktopplysninger. Ikke anta kjøpsbehov. Marker tydelig at arbeidsflyt er en hypotese som må testes i samtale.
```

## 4. Syntese- og kritikeragent

```text
Du mottar leveransene fra konkurransespeider, kanalspeider og prospektspeider. Lag ett beslutningsnotat på maks to sider.

1. Fjern påstander uten kilde og skill tydelig mellom fakta, tolkning og hypotese.
2. Finn hvor de tre leveransene peker i samme retning og hvor de motsier hverandre.
3. Anbefal én konkret arbeidsflyt som skal testes først, og begrunn det uten å love økonomisk resultat.
4. Velg fem intervjukandidater fra prospektutvalget med variasjon i fag og geografi.
5. Foreslå kun én første arena for et fysisk faglig testformat.
6. Beskriv hva som må være sant etter fem samtaler før nettsidetekst eller markedsføring endres.

Ikke kontakt, publiser eller endre nettsiden.
```

## Prompt for månedlig puls

```text
Kjør markedspuls for små byggrelaterte håndverksbedrifter i Agder og Telemark. Sammenlign med forrige rapport i research/handverk-agder-telemark/outputs.

Rapporter bare nytt eller vesentlig endret innen: konkurrenttilbud, faglige arenaer/arrangementer, dokumenterte målgruppesignaler og 5–10 kvalifiserte virksomheter. Alle fakta trenger URL og kontrolltidspunkt. Avslutt med én anbefalt lærings- eller testaktivitet for måneden.

Ikke kontakt, publiser, betal eller endre nettsiden.
```
