# Kjøringer

Lagre ferdige researchnotater her med dato først i filnavnet, for eksempel `2026-09-markedspuls.md`.

Hvert notat må si hva som er nytt, ha kilde-URL og kontrolltidspunkt, og avslutte med én konkret lærings- eller testaktivitet. Ikke lagre personopplysninger eller kontaktforsøk her.
